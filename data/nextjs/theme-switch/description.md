# Theme switch

Implement a client component `ThemeSwitch` in `components/ThemeSwitch.tsx`:

- Renders a root `<div data-testid="root">` with a `data-theme` attribute.
- The attribute starts as `"light"`.
- Renders a `<button data-testid="toggle">` that toggles `data-theme` between `"light"` and `"dark"`.
- The button text shows `"Switch to dark"` when current is light, `"Switch to light"` when current is dark.

Default export.
