# Counter button

Implement a client component `Counter` in `components/Counter.tsx` that:

- Renders a `<button>` labeled "Increment".
- Displays the current count in an element with `data-testid="count"`.
- Starts at 0; clicking the button increases the count by 1 each click.

Export the component as the default export. The starter file already has the scaffold;
fill in the missing state and click handler so the tests pass.
