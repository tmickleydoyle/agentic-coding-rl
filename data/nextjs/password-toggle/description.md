# Password show/hide

Implement a client component `PasswordField` in `components/PasswordField.tsx`:

- A controlled `<input data-testid="pw">` whose `type` is `"password"` initially.
- A `<button data-testid="toggle">` with label `"Show"` when hidden and `"Hide"` when shown.
- Clicking the button toggles the input's `type` between `"password"` and `"text"` and updates the button label.

Default export.
